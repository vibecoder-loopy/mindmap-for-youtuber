# TubeMap Design Context

## Design Context

### Users
Korean YouTubers and content creators using TubeMap as a local-first thinking workspace. They organize channel strategy, video ideas, scripts, research notes, competitor analysis, keywords, and production todos as connected nodes. Used in focused planning/ideation sessions at a desk — not a quick-glance dashboard, but a deep work surface they sit with for hours.

### Brand Personality
**Editorial · Calm · Confident.** Feels like a refined creative tool — not flashy, not gamified, not chatty. Quietly powerful. Trusts the user. The interface defers; the work is the star. Tone is closer to a well-typeset notebook than a SaaS product.

### Aesthetic Direction
- **Dark theme, refined.** Tinted near-blacks (warm grey-black, never pure #000), low-glare surfaces. Think Obsidian + ink-on-paper editorial discipline rather than "edgy gamer dark."
- **Single sharp accent.** Red `#ff2d2d` is the only chromatic note — reserved for active/selected/critical state. Everything else lives in a tinted neutral scale.
- **References:** Obsidian (graph view, restraint), Linear (typography hierarchy, color discipline), editorial print layouts (asymmetric breathing space, varied weights).
- **Anti-references (must avoid):** AI slop — neon glow, purple→cyan gradients, glassmorphism, generic "dark mode with rainbow accents," gradient text, glowing borders as decoration.
- **Typography:** Distinctive but quiet. Sharp geometric sans for UI, with intentional weight contrast. Avoid Inter/Roboto/system defaults. A subtle serif option for display headlines is welcome.

### Design Principles
1. **Quiet confidence** — chrome recedes; only active state speaks loudly. Most pixels are neutral.
2. **One accent, used sparingly** — red is a verb, not a decoration. If it's not selected/active/critical, it's not red.
3. **Hierarchy through type and space, not through containers** — vary weights, sizes, and whitespace before reaching for borders/shadows/cards.
4. **Real surfaces, not fake depth** — solid panels, hairline rules, restrained shadows. No blur, no glassmorphism, no neon glow.
5. **Every pixel earns its place** — if a decorative element doesn't reinforce the editorial tone, cut it.
